# Security Policy

## Reporting a Vulnerability

Do not publish sensitive vulnerability details in a public issue. Use GitHub private vulnerability reporting when enabled, or contact the repository owner directly.

## Repository Data Policy

This repository must never contain:

- Production credentials or access tokens
- Real customer, driver, employee, or shipment data
- Proprietary company source code
- Licensed Oracle JD Edwards binaries or restricted artifacts
- Internal hostnames, private IP addresses, or production connection strings

All ERP and logistics examples in this repository are synthetic reference implementations.
